# NGSS Curriculum Builder

A comprehensive, grade-agnostic system for tracking K-12 science learning standards across all 50 US states + District of Columbia, with grade-specific page/section mapping support.

## Recent Accomplishments

✅ **30/51 states** (59%) now have page range data
✅ **119 grade ranges** extracted across 18 states
✅ **94% success rate** using multi-phase parsing approach
✅ **Automated + manual methods** documented in `docs/LESSONS_LEARNED.md`

**Project Status:** Production-ready metadata system with extensive page range coverage

## Features

- Track state science standards by grade (K-12)
- Identify which documents cover specific grades
- Extract grade-specific page ranges and sections from PDFs
- Compare standards across all states
- Research queries for state-specific information
- Auto-detection of document organization patterns
- Confidence scoring and manual review flags

## Usage

### Querying States

**List all states:**
```bash
python state_science_standards_system.py list
```

**Search for documents covering a specific grade:**
```bash
python state_science_standards_system.py search 3
```

**Get detailed information about a state:**
```bash
# All grades
python state_science_standards_system.py state WA

# Specific grade
python state_science_standards_system.py state WA 3
```

**Show K-12 coverage for a state:**
```bash
python state_science_standards_system.py range CA
```

**Compare states for a specific grade:**
```bash
python state_science_standards_system.py compare 5
```

**Generate research queries for a state:**
```bash
python state_science_standards_system.py queries IL 4
```

### Grade-Specific Sections

**Show all grade sections for a state:**
```bash
python state_science_standards_system.py sections WA
```

**Show sections for a specific grade:**
```bash
python state_science_standards_system.py sections WA 3
```

Example output:
```
Washington (WA) - GRADE-SPECIFIC SECTIONS

Grade 3 sections:

Document: Washington State K-12 Science Learning Standards
  URL: https://ospi.k12.wa.us/sites/default/files/...
  Pages: 22-28
  Confidence: High
```

### Parsing Documents

Use parsing tools in the `scripts/` directory to extract grade section data:

**Parse specific states:**
```bash
cd scripts/parsing
uv run parse_standards.py parse --states WA,CA,OR
```

**Parse all states:**
```bash
cd scripts/parsing
uv run parse_standards.py parse --all
```

**Validate URLs:**
```bash
cd scripts/validation
uv run validate_urls.py
```

**Apply extracted page ranges:**
```bash
cd scripts/validation
uv run apply_page_ranges.py
```

See `scripts/README.md` for detailed documentation of all parsing and validation tools.

## Data Structure

### Standards Document

```python
@dataclass
class StandardsDocument:
    title: str
    url: str
    grade_levels: List[str]  # ["K", "1", "2", ...]
    document_type: str  # "complete_k12", "grade_specific", "grade_band"
    format: str = "PDF"  # "PDF", "HTML", "Interactive"
    page_range: Optional[str] = None  # "18-21"
    notes: Optional[str] = None
    grade_sections: Dict[str, GradeSection]  # NEW: Grade-specific mappings
```

### Grade Section Mapping

```python
@dataclass
class GradeSection:
    page_ranges: List[Tuple[int, int]]  # Multiple ranges supported
    section_ids: List[str]  # For HTML/interactive docs
    confidence: str  # "high", "medium", "low"
    notes: Optional[str] = None
    needs_review: bool = False  # Manual review flag
```

## Document Organization Patterns

The parser automatically detects how documents are organized:

### By Grade (Sequential)
Standards organized by grade level: Kindergarten, then Grade 1, then Grade 2...

**Detection:** "by_grade"
**Confidence:** High
**Example:** Most state K-12 documents

### By Topic (Interleaved)
Standards organized by scientific discipline across grades: All Physical Science K-5, then all Life Science K-5...

**Detection:** "by_topic"
**Confidence:** Medium
**Example:** DCI (Disciplinary Core Idea) arrangement documents
**Note:** Results in multiple page ranges per grade
